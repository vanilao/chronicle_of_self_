# Chronicle of Self - คู่มือการออกแบบเสียง

## 🎵 ภาพรวม

เสียงประกอบใน Chronicle of Self ถูกออกแบบมาให้ **เรียบง่าย น่าพึงพอใจ และไม่รบกวน** เป้าหมายคือการให้ข้อเสนอแนะทางเสียงที่สุภาพสำหรับการโต้ตอบหลักๆ โดยไม่ทำให้ผู้ใช้รู้สึกเบื่อหรือรบกวนระหว่างการใช้งานปกติ

## 🎯 หลักการออกแบบ

### 1. แนวทางแบบมินิมอล

- **น้อยแต่ดี**: ใช้เสียงเฉพาะการโต้ตอบที่มีความหมาย
- **ระยะเวลาสั้น**: สูงสุด 0.1-0.5 วินาที
- **ระดับเสียงต่ำ**: ค่าเริ่มต้น 30-50% ของระบบ
- **ไม่มีเพลงพื้นหลัง**: เน้นเสียงตอบโต้เท่านั้น

### 2. สุนทรียศาสตร์รetro

- **ได้รับแรงบันดาลจาก 8-bit/16-bit**: เสียงโทนเดี่ยวที่สะอาด
- **องค์ประกอบ Chiptune**: ความรู้สึกเกมย้อนยุคเบาๆ
- **ความชัดเจนสมัยใหม่**: สะอาด ไม่หยาบคายหรือบิดเบือน
- **Timbre ที่สอดคล้องกัน**: ครอบครัวเสียงเดียวกันทั่วทั้งเอฟเฟกต์

### 3. การเข้าถึง

- **ทางเลือกภาพ**: การโต้ตอบทั้งหมดทำงานได้โดยไม่มีเสียง
- **ตัวควบคุมระดับเสียง**: ปุ่มปิดเสียงและปรับเปลี่ยนที่ง่าย
- **ไม่มีเสียงดังพลัน**: ซองเสียงค่อยเป็นค่อยไป
- **ความถี่สมดุล**: หลีกเลี่ยงความถี่ที่ทะลุหู

## 🔊 หมวดหมู่เสียงประกอบ

### การโต้ตอบหลัก

#### การทำนิสัยสำเร็จ

- **เสียง**: กระดิ่งเบาๆ เป็นบวก (อาร์เพจเจียน C เมเจอร์)
- **ระยะเวลา**: 0.2 วินาที
- **ความถี่**: โทนกลางที่เป็นสุข
- **ความรู้สึก**: การทำสำเร็จที่น่าพึงพอใจ, รางวัลเบาๆ
- **แหล่งที่มา**: คลื่นไซน์เดี่ยวหรือตัวอย่างกระดิ่งอ่อนๆ

#### การได้รับ XP

- **เสียง**: สปาร์คเคิลขึ้นเร็ว (3-4 โน๊ต)
- **ระยะเวลา**: 0.15 วินาที
- **ความถี่**: สดใสแต่ไม่ทะลุหู
- **ความรู้สึก**: ความคืบหน้า, ความสำเร็จ
- **ความแตกต่าง**: แตกต่างกันเล็กน้อยสำหรับ XP จำนวนน้อย vs มาก

#### การเลเวลอัพ

- **เสียง**: แฟนแฟร์สั้นๆ (5-6 โน๊ต, ขึ้นแล้วลงที่เดิม)
- **ระยะเวลา**: 0.8 วินาที
- **ความถี่**: คอร์ดโปรเกรสชันเต็ม
- **ความรู้สึก**: การเฉลิมฉลอง, ถึงเป้าหมาย
- **พิเศษ**: สามารถซับซ้อนกว่าเสียงอื่นเล็กน้อย

### การนำทางและ UI

#### การคลิกปุ่ม

- **เสียง**: แตะหรือคลิกที่อ่อนๆ
- **ระยะเวลา**: 0.05 วินาที
- **ความถี่**: ระดับกลางต่ำ
- **ความรู้สึก**: ตอบสนอง, รู้สึกสัมผัส
- **การใช้งาน**: เฉพาะการกระทำหลักเท่านั้น ไม่ใช่ทุกปุ่ม

#### การสลับธีม

- **เสียง**: สวิตช์หรือสไลด์ที่นุ่ม
- **ระยะเวลา**: 0.1 วินาที
- **ความถี่**: การเปลี่ยนแปลงที่ราบรื่น
- **ความรู้สึก**: การเปลี่ยนโหมด, ราบรื่น
- **พิเศษ**: เสียงแตกต่างกันเล็กน้อยสำหรับ สว่าง→มืด vs มืด→สว่าง

#### การเปิด/ปิดโมดอล

- **เสียง**: วูชหรือป๊อปที่อ่อนๆ
- **ระยะเวลา**: 0.15 วินาที
- **ความถี่**: เหมือนการหายใจ
- **ความรู้สึก**: การปรากฏ/การหายไป
- **ทิศทาง**: เสียงต่างกันสำหรับการเปิด vs การปิด

### ระบบความสำเร็จ

#### ปลดล็อกรางวัล

- **เสียง**: สปาร์คเคิลที่น่ารางวัล (คล้าย XP แต่ซับซ้อนกว่า)
- **ระยะเวลา**: 0.4 วินาที
- **ความถี่**: สดใส, เฉลิมฉลอง
- **ความรู้สึก**: รางวัลพิเศษ, การยอมรับ
- **พิเศษ**: สามารถมีดีเลย์/การสร้างเล็กน้อย

#### เป้าหมายสตรีค

- **เสียง**: ไฟที่แตกหรือแสงรัศมีอุ่นๆ
- **ระยะเวลา**: 0.3 วินาที
- **ความถี่**: อุ่นๆ ระดับกลาง
- **ความรู้สึก**: ความสม่ำเสมอ, ความอบอุ่น
- **ความแตกต่าง**: แตกต่างกันสำหรับสตรีค 7, 30, 100 วัน

### รูปแบบไฟล์

- **รูปแบบ**: MP3 หรือ OGG สำหรับบีบอัดที่ดีที่สุด

- **ช่องสัญญาณ**: โมโน (สเตอริโอไม่จำเป็นสำหรับเอฟเฟกต์เดี่ยว)

## 🛠 การใช้งานทางเทคนิค

### Hook จัดการเสียง

```javascript
// useSound.js
const useSound = () => {
  const [isMuted, setIsMuted] = useState(false);
  const [volume, setVolume] = useState(0.4);

  const playSound = useCallback(
    (soundName, options = {}) => {
      if (isMuted) return;

      const audio = new Audio(`/sounds/${soundName}.mp3`);
      audio.volume = options.volume || volume;
      audio.playbackRate = options.rate || 1;

      audio.play().catch((e) => console.log("การเล่นเสียงล้มเหลว:", e));
    },
    [isMuted, volume]
  );

  return { playSound, isMuted, setIsMuted, volume, setVolume };
};
```

### Context Provider

```javascript
// SoundContext.js
const SoundContext = createContext();

export const SoundProvider = ({ children }) => {
  const soundSettings = useSound();

  return (
    <SoundContext.Provider value={soundSettings}>
      {children}
    </SoundContext.Provider>
  );
};
```

## 🎚️ ตัวควบคุมผู้ใช้

### การผสานรวมการตั้งค่า

- **ปุ่มหลัก**: ปิดเสียงทั้งหมด
- **แถบเลื่อนระดับเสียง**: 0-100% ค่าเริ่มต้นที่ 40%
- **ปุ่มสลับหมวดหมู่**: ตัวควบคุมแยกสำหรับ:
  - เสียงโต้ตอบ (คลิก, สลับ)
  - เสียงรางวัล (XP, ความสำเร็จ)
  - เสียงแจ้งเตือน (เลเวลอัพ, สตรีค)

### การเก็บรักษา

- เก็บการตั้งค่าใน localStorage
- เคารพสถานะปิดเสียงของระบบ
- เริ่มต้นด้วยค่าเริ่มต้นที่ปลอดภัย

## 🎵 ตัวอย่างการใช้งาน

### การทำนิสัยสำเร็จ

```javascript
const HabitCard = ({ habit, onComplete }) => {
  const { playSound } = useSound();

  const handleComplete = () => {
    onComplete();
    playSound("habit-complete");

    // เสียงโบนัสสำหรับสตรีค
    if (habit.streak > 0 && habit.streak % 7 === 0) {
      setTimeout(() => playSound("streak-milestone"), 300);
    }
  };

  return <Checkbox onClick={handleComplete}>{habit.name}</Checkbox>;
};
```

### การเลเวลอัพ

```javascript
const LevelUpModal = ({ show, newLevel }) => {

  }, [show, playSound]);

};
```

## ✅ ตัวชี้วัดความสำเร็จ

### ประสบการณ์ผู้ใช้

- เสียงช่วยเพิ่มแต่ไม่รบกวนฟังก์ชันหลัก
- ผู้ใช้สามารถปิดเสียงได้ง่ายหากไม่ต้องการ
- ไม่มีผลกระทบต่อประสิทธิภาพการโหลดหรือการโต้ตอบแอป
- เสียงทำงานสอดคล้องกันในทุกเบราว์เซอร์

### ทางเทคนิค

- ไฟล์เสียงทั้งหมดน้อยกว่า 500KB บีบอัดแล้ว
- ไม่มีความล่าช้าระหว่างการกระทำของผู้ใช้และการเล่นเสียง
- การทำงานที่ละเอียดเมื่อเสียงโหลดล้มเหลว
- ผลกระทบต่อขนาด bundle ขั้นต่ำ
