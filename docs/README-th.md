# Chronicle of Self

เกมติดตามนิสัยแนวรีโทรที่ช่วยให้คุณอัปเกรดชีวิตผ่านนิสัยประจำวัน, รางวัล XP, และปลดล็อกความสำเร็จ

## 🎮 เริ่มต้นอย่างรวดเร็ว

```bash
# โคลนที่เก็บ
git clone https://github.com/yourusername/chronicle-of-self.git
cd chronicle-of-self

# ติดตั้ง dependencies
cd frontend
npm install

# เริ่มเซิร์ฟเวอร์พัฒนา
npm start
```

เปิด http://localhost:3000 เพื่อดูแอปพลิเคชัน

## ✨ ฟีเจอร์

### ฟังก์ชันหลัก

- **การจัดการนิสัย**: สร้าง, แก้ไข, และลบนิสัยประจำวันด้วยหมวดหมู่ (ร่างกาย, จิตใจ, วิญญาณ, สร้างสรรค์)
- **ระบบ XP และการเลเวลอัพ**: ได้รับ XP สำหรับนิสัยที่ทำสำเร็จและเลเวลอัพด้วยชื่อรีโทร
- **การติดตามสตรีค**: ตรวจสอบสตรีคปัจจุบันและสูงสุดเพื่อแรงจูงใจ
- **การเลือกอาร์คไทป์**: เลือกคลาสของคุณ (นักรบ, นักปราชญ์, พระ, ช่างฝีมือ) สำหรับโบนัส XP
- **การสร้างภาพความคืบหน้า**: แผนที่ความร้อนปฏิทิน, แผนภูมิการทำสำเร็จ, และการแสดงความสำเร็จ

### ประสบการณ์ผู้ใช้

- **ดีไซน์แบนรีโทรแบน**: ขอบหนา, เงาแบน, และฟอนต์พิกเซลสำหรับความรู้สึกย้อนยุค
- **ธีมสว่าง/มืด**: สลับระหว่างธีมด้วยการตั้งค่าที่คงอยู่
- **เลย์เอาต์ที่ตอบสนอง**: ทำงานได้อย่างราบรื่นบนมือถือ, แท็บเล็ต, และเดสก์ท็อป
- **ออฟไลน์ก่อน**: ข้อมูลทั้งหมดเก็บในเบราว์เซอร์ของคุณ (localStorage)

### หน้าเพจ

- **หน้าแรก**: หน้าการตลาดพร้อมภาพรวมฟีเจอร์
- **แดชบอร์ด**: นิสัยวันนี้, ความคืบหน้า XP, และความสำเร็จล่าสุด
- **นิสัย**: จัดการนิสัยทั้งหมดด้วยตัวกรองหมวดหมู่
- **ความคืบหน้า**: การวิเคราะห์ภาพและการแสดงความสำเร็จ
- **โปรไฟล์**: สถิติผู้ใช้, การตั้งค่า, และค่ากำหนด

## 🛠 สแต็กเทคโนโลยี

- **Frontend**: React 18 + Create React App
- **UI Framework**: Material UI (MUI) พร้อมสไตล์รีโทรแบบกำหนดเอง
- **การจัดการสถานะ**: React Context API
- **การจัดการเส้นทาง**: React Router DOM v6
- **การจัดเก็บ**: localStorage (MVP), วางแผน PostgreSQL backend
- **ฟอนต์**: VT323 (ส่วนหัว), IBM Plex Mono (เนื้อหา)
- **ไอคอน**: Material UI Icons

## 🎨 ระบบการออกแบบ

### จานสี

- **โหมดสว่าง**: พื้นหลังเบจ/ครีมพร้อมแอ็กเซนต์ฟ้าสกาย
- **โหมดมืด**: พื้นหลังนาวีพร้อมแอ็กเซนต์ฟ้า/ชมพู
- **ขอบหนา**: ขอบดำ 3px สำหรับสุนทรียศาสตร์รีโทร
- **เงาแบน**: เงาดำ 4px 4px 0px

### การพิมพ์

- **ส่วนหัว**: VT323 (ฟอนต์พิกเซล)
- **เนื้อหา**: IBM Plex Mono (มอโนสเปซ)
- **พิเศษ**: Press Start 2P (องค์ประกอบแอ็กเซนต์หายาก)
