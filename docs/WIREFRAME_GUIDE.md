## 🎨 วิธีวาด Wireframe ด้วยมือ

### เครื่องมือที่ต้องใช้:
- ✏️ ดินสอ (สำหรับร่างก่อน)
- 🖊️ ปากกาดำ (สำหรับเส้นขอบสุดท้าย)
- 📏 ไม้บรรทัด (สำหรับเส้นตรง)
- 📄 กระดาษ A4 หรือ Grid Paper

### ขั้นตอนการวาด:

#### 1. กำหนดขอบจอ
```
┌─────────────────┐
│                 │
│                 │  ← วาดกรอบสี่เหลี่ยมเป็นตัวแทนจอ
│                 │
└─────────────────┘
```

#### 2. แบ่ง Layout
- วาดเส้นแนวนอนสำหรับ Navbar ด้านบน
- วาดเส้นแนวนอนสำหรับ Footer ด้านล่าง (ถ้ามี)
- แบ่งพื้นที่เนื้อหาตรงกลาง

#### 3. วาด Components
- ใช้กล่องสี่เหลี่ยม □ แทน Cards
- ใช้เส้นกรอบหนา ═══ แทน Headers
- ใช้เส้นประ ─── แทน Dividers
- ใช้ checkbox ☐ แทน input fields
- ใช้ [Button] แทน buttons
- เขียนข้อความสั้นๆ ใน components

#### 4. เพิ่ม Icons
- ใช้สัญลักษณ์ง่ายๆ: ⚔️ 📚 💖 🎨 🏆 🔥 ⚡
- หรือวาด icon เป็นวงกลมเล็กๆ พร้อมชื่อ

#### 5. ใส่ Labels
- เขียนชื่อ component ใกล้ๆ
- ใส่คำอธิบายสั้นๆ ว่าแต่ละส่วนทำอะไร
- ลูกศร → ใช้แสดงการไหลของข้อมูล

## 📐 สำหรับใช้ Lucidchart

### Shapes ที่ควรใช้:
1. **Rectangle** - Cards, Containers, Buttons
2. **Text Box** - Labels, Descriptions
3. **Line/Arrow** - Connections, Flow
4. **Circle** - Icons, Avatars
5. **Progress Bar** - Custom shape หรือ rectangle + fill

### Tips สำหรับ Lucidchart:
- ✅ ใช้ Grid (View → Show Grid) เพื่อความเรียบร้อย
- ✅ ใช้ Alignment tools (Ctrl+L, Ctrl+R, Ctrl+E)
- ✅ Copy-Paste components ที่ซ้ำกัน (เช่น cards)
- ✅ Group elements (Ctrl+G) เพื่อจัดการง่าย
- ✅ ใช้สี Gray Scale เท่านั้น (wireframe ไม่ต้องใช้สีจริง)
- ✅ Font: ใช้ Arial, Helvetica หรือ Roboto

### Layer Priority:
```
Layer 1: Background/Containers (จาง)
Layer 2: Cards/Components (ปานกลาง)
Layer 3: Text/Labels (เข้ม)
Layer 4: Icons/Buttons (เข้มที่สุด)
```
